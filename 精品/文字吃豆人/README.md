# PAC-TEXT — 纯文本吃豆人

用纯文本字符渲染的吃豆人小游戏：迷宫、豆子、能量球、鬼魂与计分全部以字符形式呈现，方向键或 WASD 操作。

## 运行

无需构建，浏览器直接打开 `index.html` 即可。点击页面获得焦点后开始游戏。

## 操作

- 方向键 / WASD —— 移动
- 吃能量球后可反杀鬼魂得分

## 文件

- `index.html` —— 全部游戏逻辑（单文件，无外部资源）
