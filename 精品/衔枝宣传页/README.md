# 衔枝宣传页（前端复刻）

单文件纯原生 HTML/CSS/JS 实现（无任何外部依赖，双击 `index.html` 即可在浏览器打开）。

复刻自抖音「衔枝 Twig」产品宣传视频中的全部展示效果与交互（原视频作者：衔枝 / 灰线，本仓库仅做前端效果复刻学习，不含原产品任何代码或数据）。

## 页面结构（12 个场景，滚动依次触发）

1. **Logo 开场** — 深绿底，标题/副标题/图标依次淡入
2. **3D 样机** — 笔记本合页 rotateY 展平
3. **记忆装载 UI** — 六节点流程轴逐个点亮、数字滚动、输入框模拟回复
4. **三层记忆卡片** — 卡片从地面（rotateX 82° 平躺）依次翻起立正，最后摆成手持牌扇形
5. **文字过渡** — 关键词金色下划线强调
6. **对比滑块** — 可拖动的 before/after 分屏（clip-path 裁切）
7. **粒子堆砌数据柱** — Canvas 粒子受重力下落、堆叠成三根数据柱（37 事件 / 12 线索 / 5 理解）
8. **认知层 UI** — 卡片布局展示理解层
9. **实测对话** — 7 条消息流式出现，置信度从 0.82 跌到 0.57（红色条同步收缩）
10. **聚光灯揭示 + 印章** — 「叙事闭环」红色印章盖下
11. **基准数据 + 彩带** — 数字翻牌 + confetti
12. **金色徽章收尾**

## 交互说明

- 页面**不自动播放**，向下滚动逐场景触发
- 场景 3：可在输入框输入文字，点击发送会出现模拟回复
- 场景 6：按住滑块左右拖动，对比两侧内容
- 场景 7：粒子落定后数字浮现；每根柱子可重放
- 场景 9：对话逐条出现后可重放
- 右侧导航可跳转到任意场景

## 技术要点

- 纯原生实现，无构建、无框架、无运行时编译
- IntersectionObserver 驱动场景进场
- Canvas 粒子物理（重力 + 水平漂移 + 落点堆叠）
- CSS 3D transform（perspective / rotateX / rotateY）实现卡片翻转
- 场景级错误隔离：单个场景初始化失败不影响整页
