# 高级书架交互 · 书架手记（前端复刻）

单文件纯原生 HTML/CSS/JS 实现（无任何外部依赖，双击 `index.html` 即可在浏览器打开；衬线字体走系统回退栈 Noto Serif SC → Songti SC → SimSun）。

复刻自抖音「怎么用 AI 做出这种高级书架交互的网页和 APP」教程视频（仅做前端效果复刻学习，不含原产品任何代码或数据）。所有画面元素均为程序化矢量绘制（SVG / CSS），不使用任何位图或视频抽帧，任意缩放下保持锐利。

在线体验（妙搭）：https://dcniaqwtmoca.feishu.cn/page/NtwRmpSbYdmb7EaKYOVcymgtndb

## 页面结构

- **书架场景**：深色暖光木质书架横排 7 本主题手账——食物志 / 梦与想 / 旅行记 / 生活本 / 工作簿 / 记账本 / 心情本，每本封面为独立矢量 SVG（布纹质感 + 烫金细框 + 主题插画）
- **详情场景**：3D 书本 + 右侧参数面板（装帧 / 开本 / 主题 / 用纸）+ 翻页导航 + 桌面文具小物（铅笔、印章、圆环、车票等）

## 交互说明（完整链路）

1. **点选** — 点哪本书书架就平移到哪本居中，全站背景主题色随之同步切换（每本书有独立配色）
2. **飞出** — 再点选中的书，书本沿贝塞尔轨迹从书架槽位飞到中央阅读台（WAAPI 驱动）
3. **封面两段式** — 点一下封面半掀开（-140°），再点摊平成跨页（-178°）
4. **翻页** — 左右拖拽或点按翻页，纸页跟随手指 3D 弯折并带动态卷曲阴影（非硬切图）；共 5 组跨页：内封 / 扉页 / 章节 / 页内插画 / 版权页
5. **合书** — 拖左缘向右可把封面拖回合上
6. **转视角** — 拖空白处旋转视角（±165°），可看到书脊、书侧与书口；一键「重置视角」回正
7. **飞回** — 关闭详情，书沿轨迹飞回书架原位

## 技术要点

- 纯原生实现，无构建、无框架、无运行时编译
- CSS 3D 书本结构：封面 / 封底 / 书脊 / 书口四面体（preserve-3d + 每面独立变换）
- 翻页为 rAF 驱动的逐帧动画（cubic ease-out），弯折阴影用 CSS 自定义属性逐帧更新
- 封面与插画全部由 JS 生成 SVG（布纹 / 烫金框 / 主题线条画），零位图资源
- 书本飞出 / 飞回用 WAAPI（element.animate）双阶段动画
- 已通过 22 项 Playwright 真浏览器自动化断言（渲染 / 主题切换 / 飞出 / 开合 / 拖拽翻页 / 转视角 / 复位 / 飞回全链路，控制台零报错）
